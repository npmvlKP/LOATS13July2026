ROOT-CAUSE FIXES
================
1. calculate_simple_pnl() — Decimal-only finance violation
   HistoricalData stores OHLC as float. The original code mixed float and
   Decimal arithmetic, raising `TypeError: unsupported operand type(s) for *:
   'float' and 'decimal.Decimal'` at runtime. Fixed by converting OHLC values
   to Decimal before calculation, preserving the project's "Decimal-only
   finance" principle.

2. Test for unsorted data reached the wrong validation
   `test_iterator_raises_on_unsorted_data` used the default window_size=20 on
   a 2-element fixture, so the size check fired before the timestamp sort
   check. Fixed by passing window_size=2 so the intended no-lookahead path is
   exercised.

3. Project-root resolution in test suite
   `Path(__file__).parent.parent.parent` resolved one directory too high in
   the nested repo layout, causing FileNotFoundError when reading
   `scheduler.py` and `fr7_health_check.py`. Added a robust
   `_find_project_root()` helper that walks up until both `src/` and
   `tests/` markers are found.
